# מטלה שישית - ירושה, סדר בנאים ומפרקים, ופונקציות וירטואליות טהורות

## יושרה אקדמית

במהלך העבודה על המטלות, מותר להתייעץ עם סטודנטים אחרים ולחפש מידע באינטרנט. עם זאת, חל איסור להעתיק קטעי קוד שלמים ממקורות חיצוניים, כולל סטודנטים אחרים, אתרי אינטרנט ומודלי בינה מלאכותית (כגון ChatGPT).

יש לדווח על כל עזרה שקיבלתם, בין אם מדובר בהתייעצות עם סטודנטים אחרים או במידע שנמצא באינטרנט, בהתאם ל[תקנון היושר של המחלקה](https://www.ariel.ac.il/wp/cs/wp-content/uploads/sites/88/2020/08/Guidelines-for-Academic-Integrity.pdf).
**במקרה של שימוש בכלי בינה מלאכותית (AI), יש לצרף את הפרומפטים שהוזנו ואת התשובות שהתקבלו**.


## הקדמה
מטלה זו היא חלק מהקורס "C++ תכנות מתקדם" ומטרתה להדגים את עקרונות **הירושה (Inheritance)** בשפת C++. המטלה מתמקדת ביישום מערכת ניהול גן חיות המבוססת על היררכיית מחלקות עם מחלקת בסיס מופשטת (Abstract Base Class) ומחלקות נגזרות.

## מבנה המטלה
במטלה זו תתבקשו לממש מספר קבצי `.cpp` על בסיס קבצי ה-`.hpp` שסופקו. המטלה מדגימה:
- **ירושה (Inheritance)** - מחלקות נגזרות יורשות ממחלקת בסיס
- **סדר בנאים ומפרקים (Order of Constructors & Destructors)** - הבנת סדר הבנייה וההריסה בהיררכיית ירושה
- **פונקציות וירטואליות טהורות (Pure Virtual Functions)** - מחלקה מופשטת שלא ניתן ליצור ממנה מופעים
- **שימוש בנושאים ממטלות קודמות** - מרחבי שמות, חריגות, בנאים, מפרקים, הקצאה דינמית

## דרישות והנחיות
- להשלים את הקוד החסר בקבצים שסופקו
- לוודא שהקוד מתקמפל ופועל ללא שגיאות
- להדגים את סדר הבנאים והמפרקים בהיררכיית ירושה
- להקפיד על כתיבה תקנית ותיעוד מתאים
- לעבור בהצלחה את הטסטים הכתובים בקובץ test.cpp

## תכונות C++ שיש להדגים
1. **ירושה (Inheritance)** - מחלקות `Mammal`, `Bird`, `Reptile` יורשות מ-`Animal`
2. **פונקציות וירטואליות טהורות (Pure Virtual Functions)** - `Animal` היא מחלקה מופשטת
3. **סדר בנאים ומפרקים** - בנאי בסיס נקרא ראשון, מפרק נגזר נקרא ראשון
4. **מפרק וירטואלי (Virtual Destructor)** - חיוני עבור מחיקה פולימורפית
5. **הקצאה דינמית ופולימורפיזם** - שימוש במצביעים למחלקת בסיס
6. **חריגות (Exceptions)** - טיפול בשגיאות עם `std::invalid_argument`
7. **מרחבי שמות (Namespaces)** - שימוש במרחב שמות `zoo`
8. **בדיקות יחידה (Unit Testing)** - שימוש בספריית doctest

## הוראות קימפול והרצה

### שימוש ב-Makefile:
הפרויקט כולל `Makefile` שמאפשר קימפול והרצה בקלות:

```bash
make              # מקמפל ומריץ את התוכנית הראשית
make test         # מקמפל ומריץ את בדיקות היחידה
make student_test # מקמפל ומריץ את הבדיקות של הסטודנט (לפחות 20 טסטים)
make tidy         # מריץ בדיקת תקינות קוד (clang-tidy)
make clean        # מנקה את כל קבצי הקימפול
```

## בדיקות סטודנט (StudentTest.cpp)

עליכם ליצור קובץ `StudentTest.cpp` שיכיל **לפחות 20 בדיקות (`TEST_CASE`) נוספות** שלא קיימות ב-`test.cpp`. הקובץ צריך:
- לכלול `#include "doctest.h"` ואת קבצי ה-header שלכם
- לכלול בדיקות שונות ומקוריות (לא העתקה של הבדיקות הקיימות)
- לכסות מקרי קצה, מצבי שגיאה, וקומבינציות שונות

המערכת בודקת אוטומטית (באמצעות doctest) שמספר הבדיקות הכולל עומד בדרישה.

## פירוט הפלט הצפוי

### הודעות בנאים ומפרקים
כל בנאי ומפרק צריך להדפיס הודעה בפורמט הבא:

| מחלקה | בנאי | בנאי העתקה | מפרק |
|--------|-------|------------|-------|
| `Animal` | `"{species} Animal constructed: {name}"` | `"{species} Animal copy-constructed: {name}"` | `"{species} Animal destructed: {name}"` |
| `Mammal` | `"Mammal constructed: {name}"` | `"Mammal copy-constructed: {name}"` | `"Mammal destructed: {name}"` |
| `Bird` | `"Bird constructed: {name}"` | `"Bird copy-constructed: {name}"` | `"Bird destructed: {name}"` |
| `Reptile` | `"Reptile constructed: {name}"` | `"Reptile copy-constructed: {name}"` | `"Reptile destructed: {name}"` |

שימו לב: בנאי `Animal` משתמש בשם **המין** (species) בהודעה, לא בשם המחלקה.

### ערכי החזרה של הפונקציות הוירטואליות

#### `makeSound()`
| מחלקה | תנאי | ערך מוחזר |
|--------|-------|-----------|
| `Mammal` | לא מבויית (`isDomesticated == false`) | `"Roar!"` |
| `Mammal` | מבויית (`isDomesticated == true`) | `"Purr..."` |
| `Bird` | יכול לעוף (`canFly == true`) | `"Tweet tweet!"` |
| `Bird` | לא יכול לעוף (`canFly == false`) | `"Squawk!"` |
| `Reptile` | ארסי (`isVenomous == true`) | `"Hisss!"` |
| `Reptile` | לא ארסי (`isVenomous == false`) | `"..."` |

#### `getAnimalType()`
| מחלקה | ערך מוחזר |
|--------|-----------|
| `Mammal` | `"Mammal"` |
| `Bird` | `"Bird"` |
| `Reptile` | `"Reptile"` |

#### `getDiet()`
| מחלקה | תנאי | ערך מוחזר |
|--------|-------|-----------|
| `Mammal` | לא מבויית | `"Meat"` |
| `Mammal` | מבויית | `"Meat and plants"` |
| `Bird` | (תמיד) | `"Seeds and insects"` |
| `Reptile` | ארסי | `"Rodents and eggs"` |
| `Reptile` | לא ארסי | `"Insects and plants"` |

#### `getDescription()`
הפורמט: `"[{type}] {name} ({species}), Age: {age}, Sound: {sound}, Diet: {diet}"`

לדוגמה: `"[Mammal] Leo (Lion), Age: 5, Sound: Roar!, Diet: Meat"`

### התנהגות `Zoo::resize()`
כאשר מערך החיות מלא ומוסיפים חיה חדשה, הקיבולת מוכפלת (×2).

### התנהגות `Zoo::removeAnimal(int index)`
הסרת חיה לפי אינדקס מזיזה את כל החיות שאחריה מקום אחד שמאלה.

## טיפים להשלמת המטלה
- קראו היטב את הוראות המטלה והבינו את הדרישות
- שימו לב לסדר הבנייה וההריסה: בנאי הבסיס נקרא **לפני** בנאי הנגזר, ומפרק הנגזר נקרא **לפני** מפרק הבסיס
- פונקציה וירטואלית טהורה (`= 0`) הופכת מחלקה למופשטת — לא ניתן ליצור ממנה אובייקט ישירות
- וודאו שהמפרק של מחלקת הבסיס הוא `virtual` כדי להבטיח מחיקה נכונה דרך מצביע לבסיס
- בדקו את התוכנית עם מקרי קצה ותנאים שונים
- הקפידו על כתיבת קוד נקי, קריא ומתועד היטב
